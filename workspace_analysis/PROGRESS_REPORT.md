## 执行摘要

本项目实现了基于 Vahrenkamp 方法的 MOZ2 双臂 7-DOF 机械臂 6D manipulability 工作空间分析框架。核心创新在于采用 **6D 位姿体素图 + 多视图 3D 投影** 的方案，而非传统的单一 3D 热力图，从而准确反映冗余机械臂在同一位置下多姿态、多构型的灵巧性分布。

**关键成果**:
- ✅ 运动学验证通过（Jacobian 误差 < 1e-6）
- ✅ 1M 样本/臂的 6D map 构建完成（约 103 万 6D voxels）
- ✅ 4 类可视化热力图生成（能力包络/稳健空间/姿态覆盖/切片图）
- ✅ 左右臂对称性验证
- ✅ 代码框架完整，可扩展至 Vahrenkamp 扩展指标和任务特定分布

## 1. 项目背景与方案设计

### 1.1 问题定义

对于 7-DOF 冗余机械臂，**不应该**将 manipulability 热力图定义为"一个 3D 位置对应一个数"。原因：
- 同一末端位置可能对应多种末端姿态
- 同一位姿可能对应多组 IK 构型
- Yoshikawa 指标、逆条件数会因此形成**分布**，而非单值

### 1.2 方案设计

采用 **两层表示**：

| 层级 | 表示 | 用途 |
|------|------|------|
| 底层 | 6D 位姿体素图 (position + orientation cell) | 保存每个 6D voxel 内多构型的统计量 |
| 展示层 | 3D 位置投影 + 明确聚合定义 | Q_pos_max / Q_pos_p50 / orientation_coverage 等 |

**默认输出 4 张图**，而非只给 1 张：

| 图 | 含义 | 用途 |
|---|---|---|
| `Q_pos_max` | 该位置所有姿态和构型中的最佳 manipulability | 能力包络、放置区域筛选（偏乐观）|
| `Q_pos_p50` | 该位置不同姿态下的中位质量 | 稳健操作空间，避免被少量好构型误导 |
| `orientation_coverage` | 该位置可达姿态 cell 的比例 | 判断该位置是否真的灵巧 |
| 切片图 | 2D 平面热力图 | 清晰显示热区边界和梯度 |

### 1.3 技术路线

**遍历方法**: 关节空间 Sobol 低差异采样（**不**采用 7D 关节均匀网格或 6D 笛卡尔 IK 遍历）

**计算流程**:
```
Sobol 采样 7D 关节空间
  ↓
FK + 6D Jacobian
  ↓
计算指标 (icn_6d, mu_6d, mu_trans)
  ↓
离散化位姿 (position voxel + orientation cell)
  ↓
稀疏 6D voxel 累积统计
  ↓
3D 位置投影 (Q_pos_max/p50/p25, coverage)
  ↓
可视化
```

**姿态离散化**: Fibonacci 球面 (80 方向) × Roll bins (12) = 960 姿态 cells

## 2. Phase 0: 运动学验证

### 2.1 验证内容

| 验证项 | 方法 | 结果 |
|--------|------|------|
| 运动学链结构 | URDF 解析 | ✅ 左右臂各 7 关节，末端偏移一致 |
| Jacobian 正确性 | 有限差分对比 | ✅ 线速度误差 ~5e-7, 角速度误差 ~5e-10 |
| 零位构型 | FK 计算 | ✅ 左右臂 X 方向对称 (±0.212m) |
| 工作空间范围 | 10k 样本快速采样 | ✅ 最大伸展 ~1.038m |
| 镜像对称性 | 同关节角左右臂对比 | ✅ 结构基本对称，右臂有 π 旋转偏移 |

### 2.2 关键发现

**Jacobian 修复**:
- 初始实现中，关节轴位置和方向未包含关节偏移变换 `T_offset`
- 修复后：在应用 `T_offset` 之后、`T_joint` 之前取关节轴
- 误差从 ~1e-1 降至 ~1e-7

**左右臂结构**:
```
Left Arm:  waist03 (0.141, 0, 0) → left01 → ... → left_ee_site
Right Arm: waist03 (-0.141, 0, 0) + rpy(0,0,π) → right01 → ... → right_ee_site
```

## 4. 结果分析

### 4.1 左臂工作空间特征

#### 4.1.1 Q_pos_max (能力包络)

**最佳操作区域** (icn_6d > 0.25):
- **位置**: X ∈ [0.2, 0.5] m, Y ∈ [-0.2, 0.4] m, Z ∈ [-0.2, 0.2] m
- **体积占比**: 约 15% 工作空间
- **物理意义**: 这是左臂最灵巧的核心区域，适合精细操作任务

**质量梯度**:
- 中心区域: icn_6d > 0.25 (黄色)
- 中间区域: 0.15 < icn_6d < 0.25 (橙-粉色)
- 边界区域: icn_6d < 0.05 (深蓝，接近奇异)

**空间分布**:
- 工作空间呈近似球形，中心偏向 X 正方向（机器人前方）
- 范围: X ∈ [-0.3, 1.0] m, Y ∈ [-0.8, 0.8] m, Z ∈ [-0.8, 0.8] m

#### 4.1.2 Q_pos_p50 (稳健灵巧空间)

**关键发现**: Q_pos_p50 > 0.15 的区域**明显缩小**，集中在 X ∈ [0.3, 0.5] m

**物理意义**:
- 很多位置虽然**存在**高质量姿态（Q_max 高）
- 但**大多数**姿态质量一般（Q_p50 低）
- 这验证了方案文档的核心观点：**不能只看 Q_max**

**实际应用**:
- 任务规划应优先使用 Q_pos_p50 > 0.15 的区域
- Q_max 高但 Q_p50 低的区域：姿态选择受限，鲁棒性差

#### 4.1.3 Orientation Coverage

**当前状态**: 最大 4%，整个工作空间基本均匀（蓝色）

**原因分析**:
- 960 个姿态 cells，1M 样本仍然稀疏
- 平均每个位置 voxel 命中 ~5 个样本
- 每个样本落入不同姿态 cell 的概率低

**改进方向**:
- 增加样本至 2-4M：coverage 可提升至 8-15%
- 自适应加密：对候选区域局部加密
- IK 复核：对低 count 高 Q_max 的 voxel 用 IK 验证

#### 4.1.4 切片图分析 (Z ≈ -0.01m)

**热区分布**:
- **最佳区域** (icn_6d > 0.25): X ∈ [0.2, 0.5] m, Y ∈ [-0.2, 0.4] m
- **良好区域** (0.15 < icn_6d < 0.25): 向外扩展约 0.2m
- **边界区域** (icn_6d < 0.05): 工作空间外围

**对称性**:
- Y 方向基本对称，符合左臂结构
- X 方向前伸区域质量更好（7-DOF 臂典型特征）

### 4.2 左右臂对称性验证

#### 4.2.1 镜像特征

| 特征 | 左臂 | 右臂 | 对称性 |
|------|------|------|--------|
| 最佳区域 X 范围 | [0.2, 0.5] m | [-0.5, -0.2] m | ✅ 完全镜像 |
| icn_6d 最大值 | 0.338 | 0.330 | ✅ 基本一致 |
| Orientation coverage | 最大 4.0% | 最大 4.2% | ✅ 基本一致 |
| 工作空间形状 | 球形偏右 | 球形偏左 | ✅ 镜像对称 |

#### 4.2.2 结构差异

**Joint 3 的 Y 偏移**:
- 左臂: `xyz="0 -0.025 -0.208"`
- 右臂: `xyz="0 +0.025 -0.208"`

**影响**:
- 左臂热区偏 Y 正方向
- 右臂热区偏 Y 负方向
- 这是设计导致的结构差异，非计算错误

### 4.3 与 Pilot (131k) 对比

| 指标 | Pilot (131k) | 1M 样本 | 提升 |
|------|--------------|---------|------|
| 位置 voxels | 89,698 | 211,455 | 2.4× |
| 6D voxels | 130,886 | 1,036,420 | 7.9× |
| Orientation coverage (max) | 1.0% | 4.0% | 4.0× |
| 切片图质量 | 稀疏点云 | 密集连续 | 显著改善 |

**质量改进**:
- 边界更清晰，热区梯度更平滑
- 可以清晰识别最佳操作区域
- 统计量更稳定（Q_p50/p25 更可靠）

## 5. 方案验证

### 5.1 与方案文档的符合度

| 设计要点 | 实施情况 | 验证结果 |
|----------|----------|----------|
| 6D voxel 设计 | ✅ 实现 | 成功保留姿态维度信息 |
| 多视图展示 | ✅ 实现 | Q_max vs Q_p50 差异明显，单图会误导 |
| Orientation coverage | ✅ 实现 | 揭示姿态多样性不足的问题 |
| Sobol 采样 | ✅ 实现 | 1M 样本 11 分钟，线性复杂度 |
| 稀疏存储 | ✅ 实现 | 内存占用合理，可扩展 |

### 5.2 关键洞察

**1. 多视图展示的必要性**

在某些位置：
- Q_pos_max = 0.25 (高质量)
- Q_pos_p50 = 0.10 (中等质量)
- Q_pos_p25 = 0.05 (低质量)

**解释**: 该位置只有少数姿态/构型灵巧，大多数姿态接近奇异。

**结论**: 如果只看 Q_max，会**高估**该位置的实际可用性。

**2. Orientation Coverage 的重要性**

某些位置虽然 Q_max 高，但 coverage < 1%，说明：
- 只能以极少数姿态到达
- 姿态调整空间极小
- 不适合称为"灵巧工作空间"

**3. Sobol 采样的有效性**

相比均匀网格 (k^7):
- k=10: 10^7 样本，分辨率仍然很粗
- Sobol 1M: 覆盖更均匀，计算量可控

## 6. 代码架构

### 6.1 文件结构

```
workspace_analysis/
├── phase0_kinematics_validation.py    # 运动学验证
├── build_manipulability_map.py        # 6D map 构建

```

### 6.2 核心类设计

**OrientationDiscretizer**:
- Fibonacci 球面采样
- Roll bins 离散化
- 旋转矩阵 → (approach_bin, roll_bin)

**VoxelStats**:
- 单个 6D voxel 的统计数据
- 保存 Q_max, Q_mean, Q_values (用于分位数)
- 保存 best_q (最佳构型)

**SparseVoxelMap**:
- 稀疏 6D voxel 存储 (hash map)
- 位置离散化 + 姿态离散化
- 3D 投影聚合

**ManipulabilityMapBuilder**:
- Sobol 采样
- FK + Jacobian + 指标计算
- 6D voxel 累积
- 结果保存 (npz + json)

### 6.3 可扩展性

**已预留接口**:
- `compute_metrics()`: 可添加 icn_ext, task-specific 指标
- `VoxelStats`: 可添加碰撞检查、自距离等字段
- `visualize_all()`: 可添加任务特定热力图

## 7. 下一步工作

### 7.1 Phase 2: Vahrenkamp 扩展指标

**目标**: 实现 icn_ext，考虑关节限位惩罚

**方法**:
- 对 64 个 6D 运动超象限 Γ ∈ {-1,+1}^6
- 构造 augmented Jacobian: J̃_Γ = L_Γ ⊙ J_w
- icn_ext = min(σ_all) / max(σ_all)

**预期**:
- 限位附近 icn_ext 应更保守
- 与 icn_6d 对比图，验证惩罚合理性

### 7.2 Phase 3: 任务特定分布

**目标**: 针对实际任务生成热力图

**任务方向**:
- 垂直托举: v_p = [0, 0, +1, 0, 0, 0]
- 向前伸手: v_p = [+1, 0, 0, 0, 0, 0]
- 水平递交: 目标方向沿人机交互区域法向
- 姿态调整: 以角速度分量为主

**输出**: 每个任务一张 task-specific heatmap

### 7.3 Phase 4: 双臂协作空间

**目标**: 分析左右臂重叠区域

**指标**:
- `reachable_both(pos)`: 左右臂都可达
- `Q_bimanual_min = min(Q_left, Q_right)`: 双臂协作质量
- `Q_either = max(Q_left, Q_right)`: 任意一臂可操作

**应用**: 双手协作抓取、递交、组装任务

### 7.4 优化方向

**1. 增加样本数**:
- 目标: 2-4M 样本/臂
- 预期 coverage: 8-15%

**2. 自适应加密**:
- 对候选区域局部加密
- 对低 count 高 Q_max 的 voxel 复核

**3. 碰撞检查**:
- 自碰撞过滤
- 与底盘/腰/头/另一臂的碰撞检查

## 8. 结论

### 8.1 主要贡献

1. **方法论创新**: 6D 位姿体素 + 多视图投影，准确反映冗余臂灵巧性分布
2. **工程实现**: 完整的 Sobol 采样 + 稀疏存储 + 可视化框架
3. **验证充分**: 运动学验证、左右臂对称性、Pilot vs 1M 对比
4. **可扩展性**: 预留 Vahrenkamp 扩展、任务特定、双臂协作接口

### 8.2 关键发现

1. **Q_max ≠ 实际可用性**: 必须同时看 Q_p50/p25 和 orientation coverage
2. **左臂最佳区域**: X ∈ [0.2, 0.5] m, Y ∈ [-0.2, 0.4] m, icn_6d > 0.25
3. **Orientation coverage 不足**: 1M 样本仅 4%，需要更大规模或自适应加密
4. **左右臂对称性良好**: 结构差异可由 Joint 3 偏移解释

### 8.3 审查建议

**建议审查重点**:
1. ✅ 运动学正确性（Jacobian 验证通过）
2. ✅ 方案设计合理性（6D voxel + 多视图）
3. ✅ 结果可解释性（热区位置、梯度、对称性）
4. ⚠️ Orientation coverage 偏低（需要更大样本）
5. 📋 后续工作规划（Phase 2-4）

**可能的改进**:
- 增加样本至 2M，提升 coverage 至 8%
- 实现 icn_ext，验证限位惩罚效果
- 添加任务特定热力图，提升实用性
