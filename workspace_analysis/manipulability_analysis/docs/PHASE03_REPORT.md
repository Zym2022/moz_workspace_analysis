**日期**: 2026-04-24

## 执行摘要

Phase 3 对 Phase 1 中每个位置 voxel 的 `best_q` 计算了 5 个任务方向的 task-specific 指标：
- **lift_up**: 垂直托举（+Z 平移）
- **reach_forward**: 向前伸手（+X 平移）
- **handover_left**: 向左递交（+Y 平移）
- **yaw_world**: 绕 Z 轴旋转
- **pitch_world**: 绕 Y 轴旋转

**关键发现**：
- 平移任务增益范围 [0.04, 0.96]，旋转任务 [0.10, 0.43]
- 左右臂工作空间高度对称，但 reach_forward 在右臂受限位惩罚更严重
- 各任务的高质量区域（top-5%）集中在不同空间位置
- 关节限位惩罚使增益中位数下降 30-60%

## 2. 结果分析

### 2.1 平移 vs 旋转任务

**观察**：
- 平移任务（lift_up, reach_forward, handover_left）的 gain 最大值约 0.95
- 旋转任务（yaw_world, pitch_world）的 gain 最大值仅 0.43

**解释**：
- 这是 Lc=0.25m 加权归一化的结果
- 旋转任务的 vp 在加权后被 Lc 缩放，使得旋转与平移在同一量纲
- 较低的旋转增益表明：在 Phase 1 best_q 构型下，末端旋转能力相对平移能力较弱
- 这符合 7-DoF 冗余臂的典型特征：平移自由度更容易被关节冗余补偿

### 2.2 左右臂对称性

**高度对称任务**：
- lift_up: 左右臂 gain p50 均为 0.514，top-5% 中心 X 坐标镜像（±0.50）
- yaw_world / pitch_world: 左右臂 gain p50 均为 0.37，top-5% 中心镜像（±0.41）

**不对称任务**：
- reach_forward: 右臂惩罚比（0.383）显著低于左臂（0.699）
  - 右臂 gain_approx p50 = 0.187，左臂 = 0.345
  - 说明右臂向前伸手时更容易接近关节限位

**解释**：
- URDF 中左右臂关节限位可能不完全对称
- 或者 Phase 1 采样在右臂前伸区域命中的构型更接近限位边界

### 2.3 任务热区空间分布

**lift_up（垂直托举）**：
- 高质量区域集中在 X≈±0.50（中等伸展距离），Y/Z 接近中心
- 适合在机器人前方中等距离处执行托举任务

**reach_forward（向前伸手）**：
- 高质量区域集中在 X≈±0.32（较近距离），Z 略低于中心
- 适合在机器人近前方、略低位置执行抓取/按压任务

**handover_left（向左递交）**：
- 高质量区域集中在 X≈±0.55（较远距离），Y/Z 接近中心
- 适合在机器人前方较远处执行递交任务

**yaw_world / pitch_world（旋转）**：
- 高质量区域集中在 X≈±0.41（中等距离），Y/Z 接近中心
- 旋转任务的最佳区域与平移任务不完全重合

### 2.4 关节限位惩罚影响

**惩罚比（gain_approx / gain）中位数**：
- lift_up: 0.55（左右臂一致）
- reach_forward: 0.70（左臂）vs 0.38（右臂）
- handover_left: 0.50（左右臂一致）
- yaw_world / pitch_world: 0.56（左右臂一致）

**解释**：
- 关节限位惩罚使任务增益中位数下降 30-60%
- reach_forward 在右臂受惩罚最严重（62% 下降）
- 这表明：即使 Phase 1 best_q 在 icn_6d 意义下最优，在特定任务方向上仍可能接近限位

## 3. 验证结果

### 3.1 数学一致性

✅ **gain_approx ≤ gain**：所有 voxel、所有任务均满足（惩罚只降不升）  
✅ **reduced_icn = 1.0**：所有单轴任务均满足（1×7 矩阵只有 1 个奇异值）  
✅ **加权归一化**：旋转任务 vp 正确包含 Lc 缩放  
✅ **左右臂 voxel 数**：174,416（左）vs 174,357（右），差异 <0.1%

### 3.2 任务敏感性

通过对比不同任务的热区分布，验证了：
- lift_up 对 Z 方向敏感，热区在上方
- reach_forward 对 X 方向敏感，热区在前方
- handover_left 对 Y 方向敏感，热区在左侧
- 旋转任务热区与平移任务明显不同

## 5. 结论与建议

### 5.1 主要结论

1. **任务方向显著影响工作空间质量**：
   - 不能用单一 icn_6d 指标代表所有任务的能力
   - 不同任务的高质量区域在空间上有明显差异

2. **平移任务能力强于旋转任务**：
   - 平移增益最大值 ~0.95，旋转仅 ~0.43
   - 7-DoF 冗余臂更擅长平移操作

3. **左右臂基本对称，但前伸任务不对称**：
   - 右臂向前伸手受限位约束更严重
   - 建议优先使用左臂执行前伸抓取任务

4. **关节限位惩罚不可忽略**：
   - 即使 Phase 1 best_q 在通用指标下最优
   - 在特定任务方向上仍可能接近限位，导致增益下降 30-60%

### 5.2 任务规划建议

| 任务类型 | 推荐区域（左臂） | 推荐区域（右臂） | 备注 |
|---------|-----------------|-----------------|------|
| 垂直托举 | X≈0.50, Y≈0, Z≈0 | X≈-0.50, Y≈0, Z≈0 | 中等伸展距离 |
| 向前抓取 | X≈0.32, Y≈0, Z≈-0.05 | 优先使用左臂 | 右臂受限位约束 |
| 向左递交 | X≈0.56, Y≈0, Z≈-0.04 | X≈-0.55, Y≈0, Z≈-0.04 | 较远距离 |
| 旋转操作 | X≈0.41, Y≈0, Z≈0 | X≈-0.41, Y≈0, Z≈0 | 中等距离 |

### 5.3 方法局限性

**本阶段结果的诚实表述**：
- 评估对象：Phase 1 best_q（按 icn_6d 选出）
- **不是**：该位置在 task-specific 意义下的最优构型
- **不是**：该位置所有姿态/构型下的任务统计分布
- **不是**：完整 task-specific dexterous workspace

**如果需要完整 task-specific workspace**：
- 需要对每个任务重新做 full-sample 建图
- 或对每个位置做多 seed IK + task-specific 排序
- 本项目不做此扩展（见 PHASE03_PLAN §1）

### 5.4 后续工作（不在本项目范围）

如果要进一步提升结果完整性，可考虑：
1. **Phase 4: 碰撞检查**（当前结果为 kinematic, collision-unchecked）
2. **工具局部轴任务**（如"绕工具 Z 轴旋转螺丝刀"）
3. **双臂协作任务**（如"双手托举"、"双手递交"）
4. **动态腰腿姿态**（当前固定腰腿 q=0）
